Our team plans to build an **interactive San Marcos Campus & Community Map** that helps Texas State students and visitors explore the area around campus. The application will combine multiple Turf.js spatial analysis tools to provide:

- **Buffer zones** around campus buildings (5/10/15-minute walking radii)
- **Walking routes** between popular destinations with distance markers
- **Service-area polygons** for amenities such as dining halls, libraries, and bus stops, with area statistics

Users will be able to toggle layers, click features for details, and view the team behind the project through the *About Us* dropdown.

> This idea is tentative and will be refined as the project progresses.
